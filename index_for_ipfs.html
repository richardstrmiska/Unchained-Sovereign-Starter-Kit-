How to use this bundle

  1. Download this ZIP and unpack locally.
  2. Upload the entire folder (all files plus this index) to an IPFS pinning service such as web3.storage, nft.storage, or Pinata.
  3. After upload, the service will return a CID. Use a gateway link like https://ipfs.io/ipfs/<CID>/index_for_ipfs.html to reach this landing page directly.
  4. Create a QR code that points to the gateway link above (the one ending in /index_for_ipfs.html) — that ensures scanners go straight to the landing page and files.

Notes: If a gateway returns a blank page, try alternative gateways (ipfs.io, cloudflare-ipfs.com, w3s.link, gateway.pinata.cloud). Ensure the CID is the folder root and that index_for_ipfs.html exists at that root.
